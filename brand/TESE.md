# Logica Pilot — tese de marca

## Tese em uma frase

**A web não precisa ser vista por uma máquina. Precisa ser compreendida, percorrida e lembrada por ela — sob o seu controle.**

O Logica Pilot transforma o browser do usuário em infraestrutura soberana para agentes e crawlers. Ele não terceiriza sessões, memória ou aprendizado a um scraper remoto. Ele opera localmente, no browser real já autenticado, interpreta páginas por intenção e índice semântico e acumula conhecimento por site. Quanto mais navega, melhor conhece o território.

## A grande ideia: a web como território legível

Os navegadores foram desenhados para olhos. Scrapers tradicionais tratam a web como uma pilha de HTML instável. Agentes visuais tratam cada página como uma imagem cara. Nos dois casos, a máquina recebe ruído demais e contexto de menos.

O Logica Pilot propõe outro modelo: **a página é um território indexado**. O mapa semântico de acessibilidade + DOM reduz a interface ao que importa para agir — intenções, relações, estados e alvos. A IA navega pelo significado, não pela decoração. Em medições reais, isso usa de **5 a 185× menos tokens que HTML cru**.

Essa leitura não termina na primeira visita. O Pilot guarda memória por site, reconhece rotas, repara mudanças e melhora a execução. O produto deixa de ser uma automação descartável e vira uma infraestrutura que aprende.

## O inimigo

**A web alugada.**

É o modelo em que cada ação depende de uma sessão em nuvem, cada página volta a ser desconhecida, cada mudança quebra um seletor e cada escala exige comprar mais requisições. O usuário entrega login, contexto e telemetria; recebe de volta uma chamada de API sem memória.

O inimigo não é apenas “scraping caro”. É a dependência estrutural de uma camada remota que nunca aprende o seu território e nunca é realmente sua.

## A categoria que criamos

### Navegação Soberana para Máquinas

Uma categoria entre browser de IA, runtime de agentes e plataforma de scraping. Seu princípio é simples: percepção, sessão, memória e execução ficam próximas do usuário — no browser e na máquina que ele controla.

O Logica Pilot é a primeira expressão completa dessa categoria:

- **Percebe** por intenção e índice semântico, não por pixel.
- **Age** no browser real, inclusive em sessões já autenticadas.
- **Aprende** cada site e se auto-conserta com o uso.
- **Escala** de uma ação no browser a crawlers, filas, APIs, Actors e Store.
- **Permanece local**, privado e sem dependência de Playwright ou de um scraper na nuvem.

## A mudança de paradigma

| Antes | Com o Logica Pilot |
|---|---|
| A página é uma imagem ou um bloco de HTML | A página é um mapa de intenções |
| Cada execução começa do zero | Cada site vira conhecimento acumulado |
| A sessão precisa subir para a nuvem | O browser autenticado continua na sua máquina |
| Escalar significa comprar chamadas | Escalar significa reutilizar aprendizado |
| O scraper é um serviço alugado | A infraestrutura pertence a quem opera |
| Browser agent e crawler são produtos separados | Navegação e extração são o mesmo motor |

## Promessa central

**Dê à máquina um destino, não uma captura de tela.**

O Logica Pilot encontra a rota, entende a página, executa no seu browser e se lembra do caminho. Do primeiro clique a uma operação completa de scraping, o território continua sob seu controle.

## Pilares de prova

### 1. Percepção sem desperdício

O mapa semântico a11y + DOM entrega à IA apenas o que é acionável e relevante. Não é uma promessa estética; é uma vantagem mensurável de **5 a 185× menos tokens que HTML cru**.

### 2. Sessão soberana

O Pilot usa o browser real do usuário, já logado, via CDP puro. Cookies, autenticação e contexto não precisam migrar para uma infraestrutura de terceiros.

### 3. Memória que vira moat

O conhecimento por site persiste localmente. Rotas bem-sucedidas, estruturas e reparos deixam de ser custo recorrente e viram ativo acumulado. O produto fica mais barato, rápido e confiável com o tempo.

### 4. Plataforma, não truque

São 82 ferramentas reunindo motor HTTP + adaptativo, fila durável, API REST compatível com ScrapingBee, crawler com `pageFunction`, fingerprints realistas, descoberta de APIs, Actors empacotáveis e Store compartilhável. Paridade operacional com plataformas de scraping — sem transformar a infraestrutura em aluguel.

## Tom de voz

### Como falamos

- **Declarativo:** frases curtas, verbos ativos, uma ideia forte por bloco.
- **Técnico com propósito:** detalhes aparecem como prova, não como ornamentação.
- **Concreto:** “5 a 185× menos tokens”, “browser já logado”, “82 ferramentas”.
- **Soberano, não paranoico:** controle e privacidade como vantagem estrutural, sem discurso de medo.
- **Confiante sem grandiosidade:** mostramos o mecanismo; evitamos superlativos vazios.

### Vocabulário proprietário

Usar: **território, rota, intenção, índice, mapa semântico, memória local, sessão soberana, infraestrutura própria, aprender o site, comando**.

Evitar: “revolucionário”, “mágico”, “game changer”, “IA de ponta”, “copiloto inteligente”, “scraping sem esforço”, “automação ilimitada”.
